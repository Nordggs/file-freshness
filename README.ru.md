# File Freshness

Подсвечивает недавно изменённые файлы в File Explorer Obsidian маленькой
цветной точкой слева от имени файла — как свежие метки в Total Commander.

- Изменён **менее 60 мин** назад → зелёная точка (настраивается).
- Изменён **60–180 мин** назад → янтарная точка (настраивается).
- Более старые файлы → стандартный стиль темы, без остаточных классов.

File Freshness не изменяет файлы, frontmatter, временные метки файловой
системы, сортировку и структуру vault. Он лишь добавляет временные
CSS-классы элементам File Explorer.

File Freshness v1 работает в главном окне Obsidian; popout Explorer
не гарантируется.

## Локальная установка (простой способ)

Ничего устанавливать и собирать не нужно. Достаточно скачать готовый ZIP,
распаковать его и скопировать папку плагина в Obsidian.

Для обычной локальной установки **не нужны**:

- Node.js;
- npm;
- командная строка;
- сборка из исходников.

Шаги:

1. Скачайте готовый ZIP плагина `file-freshness-v0.2.0.zip`.
2. Распакуйте ZIP — получится папка `file-freshness`.
3. Скопируйте папку `file-freshness` **целиком** в
   `<vault>/.obsidian/plugins/` (где `<vault>` — папка вашего хранилища).
4. Перезапустите Obsidian (или обновите окно через `Ctrl+R`).
5. Откройте Настройки → Community plugins → включите **File Freshness**.

Внутри установочной папки находятся только готовые файлы:

- `main.js`
- `manifest.json`
- `styles.css`

В установочный ZIP не входят: `node_modules`, `src`, `tests`,
`package.json`, `package-lock.json`, конфигурационные файлы разработки, `.git`.

## Установка для разработчиков

Если хотите собрать плагин из исходников:

1. Сборка: `npm install && npm run build` внутри `file-freshness/` → `main.js`.
2. Скопируйте `manifest.json`, `main.js`, `styles.css` в
   `<vault>/.obsidian/plugins/file-freshness/`.
3. Перезагрузите Obsidian, включите «File Freshness» в Community plugins.

Позже: дистрибуция через BRAT — post-v1 шаг после переезда плагина
в собственный GitHub-репозиторий.

## Настройки

Пороги (минуты), режимы точки/текста/фона/полосы, цвета,
интервал автообновления (15–60 сек, по умолчанию 60 сек) и кнопка
«Refresh now». По умолчанию показана только точка, поэтому темы,
иконки Iconize и ручные цвета продолжают работать.

## Разработка

- `npm test` — проверка типов (`tsc`), затем unit-тесты `node --test` (jsdom).
- `npm run build` — проверка типов + сборка бандла в `main.js`.
